# DigitWorld - Spletna stran

Moderna spletna stran za podjetje DigitWorld, ki ponuja digitalne rešitve, hologramsko oglaševanje in rešitve Industrije 5.0.

## 🚀 Značilnosti

- Digitalno Matrix ozadje s kodami
- WebGL animacije s Three.js
- Interaktivni 3D hologram
- Popolnoma odziven dizajn (responsive)
- Modra digitalna barvna shema
- Animacije ob scrollanju in hoverju

## 📦 Tehnologije

- HTML5
- CSS3 (animacije, grid, flexbox)
- JavaScript (ES6)
- Three.js (WebGL 3D animacije)
- Font Awesome (ikone)
